# Contributing

Each contribution should improve one named recipe or the repository authoring standard.

## Required qualities

- Problem-led rather than feature-led
- Bulk-safe and governor-aware
- Security-conscious
- Independently testable
- Honest about failure and transaction semantics
- Deployable within its declared recipe boundary
- Free of proprietary code and data

Read [the recipe standard](docs/RECIPE-STANDARD.md) before adding implementation metadata.
